* EyeSearch - Visible-window-first isearch
EyeSearch enhances isearch by prioritizing matches visible in the current window.

When you start searching, the first match jumped to is the *closest one to your cursor within the visible window*. If no match is visible, it falls back to standard isearch behavior. All other isearch behavior (=C-s= / =C-r= cycling, keybindings, regexp support) remains unchanged.

Uses =isearch-search-fun-function=, the official isearch extension point.

** Motivation
I started to use =avy-isearch= for daily use, it had one annoying thing. When I want to go to previous point of text, but I need to decide to use isearch *backward/forward* each time.
When use forward and match the forward, *the point I want to go to is invisible*. oops.
This tiny package resolves to the pitfall of it. But you do not need use this if default isearch's behavior is not problem.

* Install
Use such a way to install:

- use =package.el= for version control
- use =straight.el= or =elpaca=
- Just download =eyesearch.el= and put it to =load-path=

#+begin_quote
I recommend to use =elpaca= for speed. If you want to stay standard way, use =package.el=
#+end_quote

* Usage

#+begin_src emacs-lisp
;; Enable for all buffers
(global-eyesearch-mode 1)

;; Or enable per-buffer
(add-hook 'prog-mode-hook #'eyesearch-mode)
#+end_src

Then use =C-s= / =C-r= as usual. The first match will jump to the closest visible match instead of the nearest one by buffer position.
